# Piko Android Fork

An independently maintained Android fork of [NihilDigit/piko](https://github.com/NihilDigit/piko), maintained by [1062624546](https://github.com/1062624546). This is neither an official upstream release nor an official PikPak client.

Only Android 8.0+ is maintained and released here. Windows, macOS and Linux are supported by upstream; retained desktop code is outside this fork's maintenance scope.

Features include PikPak file management, transfers, video playback, a dedicated share tab, share history, directory search, temporary previews and Android update checks.

Download signed universal APKs from [this repository's Releases](https://github.com/1062624546/piko/releases). Install version 1.3.1 or later manually once to migrate from the old update channel. Later releases use this repository's public GitHub release API with a release.json fallback and SHA-256 verification. Android confirms installation.

This fork remains licensed under [AGPL-3.0-or-later](LICENSE). Preserve upstream copyright and third-party notices. Android bundles GPLv3 builds of mpv and FFmpeg. Corresponding source and build files accompany releases.

See the [Chinese README](README.md) for changes, build guidance and full acknowledgments. Changes dated 2026-10-11 cover the Android-only maintenance scope and this repository's update channel.
